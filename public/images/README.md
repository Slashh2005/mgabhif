# Website images

Upload your photos into the matching folder below. Any file name works, but
the suggested names make it easy to match each photo to its spot on the site.
Use JPG or PNG for photos, and SVG or PNG for logos. Photos should be at least 1600px wide.

| Folder | What goes here | Suggested files |
|---|---|---|
| `logo/` | Company logo, plus a white version if you have one | `logo.svg`, `logo-white.svg` |
| `hero/` | Large banner photos for the top of each page | `home.jpg`, `about.jpg`, `services.jpg`, `experience.jpg`, `operations.jpg`, `contact.jpg` |
| `services/` | One photo per service | `plant-hire.jpg`, `commodity-export.jpg`, `mining-services.jpg`, `petroleum-supply.jpg` |
| `operations/` | Sites, fleet and the supply chain | `gauteng-midrand.jpg`, `mpumalanga.jpg`, `middelburg.jpg`, `rustenburg.jpg`, `mooinooi.jpg`, `burgersfort.jpg`, `fleet.jpg` |
| `about/` | Team, leadership, community and safety | `team.jpg`, `leadership.jpg`, `community.jpg`, `safety.jpg` |
| `partners/` | Partner logos (only ones you have permission to use) | `exxaro.png`, `black-wattle.png`, `mining-indaba.png`, ... |

To upload on GitHub: open the folder, click **Add file → Upload files**, then commit.
